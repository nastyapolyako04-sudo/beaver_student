## 1. Базовые концепции Bash-скриптов

### Что такое Bash-скрипт?
Bash-скрипт — это текстовый файл, содержащий последовательность команд, которые интерпретатор командной строки (`bash`) выполняет по очереди, точно так же, как если бы вы вводили их вручную в терминал.

### Первая строка: Шебанг (Shebang) `#!/bin/bash`
Каждый скрипт начинается со строки:
```bash
#!/bin/bash
```
* **Зачем нужен:** символ `#!` сообщает ядру Linux, какую программу нужно вызвать для интерпретации этого файла. `/bin/bash` — это абсолютный путь к интерпретатору Bash.
* **Что спросит препод:** *«Что будет, если не написать шебанг?»*  
  *Ответ:* Если запустить скрипт через `./script.sh`, система попытается выполнить его текущей оболочкой по умолчанию (например, sh или zsh), что может привести к ошибкам синтаксиса, специфичного для Bash.

### Права доступа и запуск (`chmod +x`)
По умолчанию созданный файл имеет только права на чтение и запись (`rw-`). Чтобы сделать его программой, нужно дать право на выполнение (*execute*):
```bash
chmod +x script.sh
```
* **Запуск скрипта:** `./script.sh`  
  Символы `./` означают *«искать исполняемый файл в текущей директории»* (по соображениям безопасности текущая папка обычно не включена в системную переменную `$PATH`).

## 2. Переменные и арифметика

### Присваивание и использование
```bash
NAME="Nikita"
COUNT=5
```
> **Критически важно:** Вокруг знака `=` **нельзя ставить пробелы**! Если написать `NAME = "Nikita"`, Bash воспримет `NAME` как имя команды, а `=` и `"Nikita"` — как её аргументы.

Для чтения значения переменной используется знак `$`:
```bash
echo "Привет, $NAME! Количество: $COUNT"
```

### Разница между одинарными и двойными кавычками
* **Двойные кавычки `""`**: поддерживают интерполяцию переменных. Переменная `$VAR` внутри заменится на её значение.
* **Одинарные кавычки `''`**: экранируют всё абсолютно буквально. Строка `'$VAR'` выведет текст `$VAR`.

### Специальные встроенные переменные Bash
| Переменная | Что содержит |
| :--- | :--- |
| `$0` | Имя самого запущенного скрипта |
| `$1`, `$2`, ... | Аргументы, переданные скрипту при запуске (`./script.sh arg1 arg2`) |
| `$#` | Общее количество переданных аргументов |
| `$@` или `$*` | Список всех переданных аргументов |
| `$?` | Код завершения последней выполненной команды (0 = успех, не 0 = ошибка) |
| `$USER` | Логин текущего пользователя системы |
| `$PWD` | Полный путь к текущей рабочей директории |
| `$EUID` | Числовой ID текущего пользователя (у `root` всегда равен `0`) |

### Арифметика в Bash
Встроенная арифметика Bash работает через конструкцию `$(( выражение ))`:
```bash
AGE=$((2026 - 2000))       # Результат: 26
NEXT=$((COUNT + 1))        # Результат: 6
IS_EVEN=$((COUNT % 2))     # Остаток от деления (по модулю)
```
> **Ограничение Bash:** Bash умеет работать **только с целыми числами**. Если попытаться вычислить `70 / (1.75 * 1.75)`, Bash выдаст ошибку `syntax error: invalid arithmetic operator`.

### Утилита `bc` (Basic Calculator)
Для работы с числами с плавающей точкой (дробными числами) используют утилиту `bc`, передавая в неё выражение через пайплайн:
```bash
bmi=$(echo "70 / (1.75 * 1.75)" | bc)
```

### Запрос пользовательского ввода (`read`)
Команда `read` ожидает ввода от пользователя с клавиатуры:
```bash
read -p "Введите ваше имя: " username
```
Флаг `-p` выводит текст подсказки (*prompt*) перед вводом.

## 3. Управляющие конструкции: Условия и Циклы

### Конструкция `if ... then ... else ... fi`
```bash
if [ условие ]; then
    команды
elif [ другое_условие ]; then
    команды
else
    команды
fi
```
> **Внимание:** Скобки `[` и `]` — это на самом деле вызов команды `test`. Поэтому **пробелы после `[` и перед `]` строго обязательны!**

#### Основные операторы сравнения:
* **Для чисел:** `-eq` (равно), `-ne` (не равно), `-lt` (меньше), `-le` (меньше или равно), `-gt` (больше), `-ge` (больше или равно).
* **Для строк:** `==` (равно), `!=` (не равно), `-z "$str"` (строка пустая), `-n "$str"` (строка не пустая).
* **Для файлов:**
  * `-f "$file"` — файл существует и является обычным файлом.
  * `-s "$file"` — файл существует и его размер **больше 0 байт** (не пустой).
  * `-d "$dir"` — директория существует.

### Конструкция `case ... in ... esac`
Идеальна для множественного выбора числовых или строковых значений:
```bash
case $VAR in
    0) echo "Ноль" ;;
    1) echo "Один" ;;
    *) echo "Всё остальное" ;;
esac
```
Символы `;;` служат аналогом `break` в других языках.

### Цикл `for`
1. **Перебор списка или диапазона:**
```bash
for i in {1..10}; do
    echo "Номер $i"
done
```
2. **Перебор файлов по маске (globbing):**
```bash
for file in *.fasta; do
    echo "Обработка файла $file"
done
```
3. **C-подобный синтаксис:**
```bash
for ((i = 1; i <= 20; i++)); do
    echo $i
done
```

### Цикл `while`
Выполняется, пока условие истинно:
```bash
i=10
while [ $i -ge 1 ]; do
    echo $i
    i=$((i - 1))
done
```

### Управление циклом: `continue` и `break`
* `continue` — немедленно завершает текущую итерацию и переходит к следующей.
* `break` — полностью прерывает выполнение цикла и выходит из него.

### Функции
```bash
check_root() {
    if [ "$EUID" -ne 0 ]; then
        echo "Ошибка: нужны права root!"
        exit 1
    fi
}

# Вызов функции:
check_root
```
Команда `exit 1` аварийно завершает весь скрипт с кодом ошибки `1` (любое число отличное от 0 означает ошибку).

## 4. Текстовые фильтры и утилиты: Grep, Sed, Awk

### Grep — поиск по шаблону
Утилита `grep` фильтрует строки, соответствующие регулярному выражению.

* `grep "pattern" file.txt` — базовый поиск.
* **Флаги:**
  * `-i` (*ignore-case*) — не учитывать регистр символов (найдет и `conf`, и `CONF`).
  * `-v` (*invert-match*) — инвертировать поиск: вывести строки, где шаблона **нет** (например, `grep -v "^>"` убирает заголовки FASTA).
  * `-o` (*only-matching*) — выводить не всю строку, а только совпавшую подстроку (удобно для подсчета вхождений через `wc -l`).
  * `-E` (*extended-regexp*) — включить расширенные регулярные выражения (позволяет использовать оператор ИЛИ `|` и группировку `()`).

#### Регулярные выражения в Grep:
* `^` — привязка к началу строки (например, `^$USER:` найдет строку, строго начинающуюся с имени пользователя).
* `$` — привязка к концу строки (например, `\.conf$` найдет строки, оканчивающиеся на `.conf`).
* `\.` — экранирование точки (точка в регулярках означает «любой символ», поэтому для поиска буквальной точки пишем `\.`).
* `(jpg|png|gif)` — логическое ИЛИ между вариантами.

---

### Sed — потоковый редактор (Stream Editor)
Используется для построчной трансформации текста (чаще всего поиска и замены).

Синтаксис команды замены:
```bash
sed -i 's/что_ищем/на_что_меняем/g' файл
```
* `-i` (*in-place*) — перезаписывает исходный файл на месте, сохраняя результат. Без `-i` результат выводится в терминал, а исходный файл не меняется.
* `s` (*substitute*) — операция замены.
* `g` (*global*) — заменить все вхождения в строке, а не только первое.

#### Альтернативные разделители в Sed:
Обычно в `sed` разделителем является слэш `/`. Но если мы заменяем файловые пути (где слэшей очень много), приходится экранировать каждый слэш:
```bash
sed -i 's/\/var\/lib\/mysql\/data/\/mnt\/ssd\/mysql/g' file   # Ужасно нечитаемо!
```
Вместо слэша можно использовать **любой другой символ**, например `|`:
```bash
sed -i 's|/var/lib/mysql/data|/mnt/ssd/mysql|g' file          # Чисто и наглядно!
```

---

### Awk — язык обработки столбцов и табличных данных
`awk` читает текст построчно, автоматически разбивая каждую строку на поля (столбцы).

#### Встроенные переменные Awk:
* `$0` — вся текущая строка целиком.
* `$1`, `$2`, `$3`, ... — первое, второе, третье поле строки.
* `$NF` — последнее поле текущей строки (`NF` = Number of Fields).
* `NR` — порядковый номер текущей строки (`NR` = Number of Records).
* `-F,` — задать разделитель полей (по умолчанию разделителем является любое количество пробелов или табов, для CSV указывают `-F,`).

#### Специальные блоки:
* `BEGIN { ... }` — выполняется **один раз до** начала чтения файла.
* `{ ... }` — выполняется для **каждой** строки.
* `END { ... }` — выполняется **один раз после** прочтения всех строк (идеально для суммирования и средних значений).

## 5. Построчный разбор всех скриптов проекта

### 1. `hello.sh`
```bash
#!/bin/bash
echo "Привет, это мой первый исполняемый скрипт!"
```
* `echo` выводит строку текста в стандартный поток вывода (`stdout`).

### 2. `age.sh`
```bash
#!/bin/bash
CURRENT_YEAR=2026
BIRTH_YEAR=2000
AGE=$((CURRENT_YEAR - BIRTH_YEAR))

echo "Текущий год: $CURRENT_YEAR"
echo "Ваш примерный возраст: $AGE"
```
* `$((...))` вычисляет разность двух целочисленных переменных.
* В строках `echo` переменные подставляются напрямую благодаря двойным кавычкам.

### 3. `bmi.sh`
```bash
#!/bin/bash
read -p "Введите массу (в кг): " weight
read -p "Введите рост (в метрах): " height

height="${height//,/.}"
weight="${weight//,/.}"

bmi=$(echo "$weight / ($height * $height)" | bc)

echo "Индекс массы тела: $bmi"
```
* `read -p` считывает введенные данные.
* `${height//,/.}` — конструкция замены в Bash: если пользователь случайно ввел `1,75` вместо `1.75`, запятая автоматически заменится на точку.
* `echo "..." | bc` вычисляет формулу $\text{ИМТ} = \frac{m}{h^2}$. Поскольку `scale` в `bc` по умолчанию равен 0, результат деления автоматически усекается до целого числа, как требовалось в задании.

### 4. `status.sh`
```bash
#!/bin/bash
echo "Пользователь: $USER"
echo "Текущее время: $(date +"%H:%M:%S")"
echo "Путь: $PWD"
echo "Аргументов: $#"
```
* `$(command)` — подстановка команд (*command substitution*): выполняет команду `date +"%H:%M:%S"` и вставляет её вывод в строку.
* `$USER` и `$PWD` берутся из системного окружения, `$#` возвращает число параметров скрипта.

### 5. `log.sh`
```bash
#!/bin/bash
FILE_PATH="./system.log"
ERROR_CODE=1

if [ -f "$FILE_PATH" ]; then
    echo "Лог-файл найден."
else
    echo "Ошибка: файл не существует."
fi

case $ERROR_CODE in
    0) echo "Статус: Ошибок нет." ;;
    1) echo "Статус: Критическая ошибка!" ;;
    *) echo "Статус: Неизвестный код." ;;
esac
```
* `[ -f "$FILE_PATH" ]` проверяет наличие файла на диске.
* `case $ERROR_CODE in ... esac` сравнивает число со списком возможных значений.

### 6. `impulse.sh`
```bash
#!/bin/bash
if [ -z "$1" ] || [ -z "$2" ]; then
    echo "Ошибка: недостаточно входящих данных"
    exit 1
fi

echo "Экспрессия гена $1 составляет $2 единиц"
```
* `[ -z "$1" ]` проверяет, пуст ли первый аргумент.
* `||` — логическое ИЛИ: если не передан либо первый, либо второй аргумент, скрипт завершается с ошибкой (`exit 1`).

### 7. `odd_filter.sh`
```bash
#!/bin/bash
for ((i = 1; i <= 20; i++)); do
    if [ $i -eq 15 ]; then
        break
    fi

    if [ $((i % 2)) -eq 0 ]; then
        continue
    fi

    echo $i
done
```
* Если `$i == 15`, `break` мгновенно прерывает цикл.
* Если `$((i % 2)) == 0` (число делится на 2 без остатка), `continue` пропускает шаг, не выводя четное число.
* В итоге выводятся нечетные числа: `1, 3, 5, 7, 9, 11, 13`.

### 8. `files_roundtrip.sh`
```bash
#!/bin/bash
for i in {1..10}; do
    touch "test${i}.txt"
done

i=10
while [ $i -ge 1 ]; do
    rm "test${i}.txt"
    i=$((i - 1))
done
```
* `touch "test${i}.txt"` создает пустой файл.
* `while [ $i -ge 1 ]` в обратном порядке уменьшает счётчик `$i` и удаляет созданные файлы по одному.

### 9. `nucleotides_count.sh`
```bash
#!/bin/bash
printf "%-15s %-7s %-7s %-7s %-7s\n" "Файл" "A" "T" "G" "C"

for file in *.fasta; do
    if [ ! -s "$file" ]; then
        continue
    fi

    a=$(grep -v "^>" "$file" | tr -d '\n' | grep -o "A" | wc -l)
    t=$(grep -v "^>" "$file" | tr -d '\n' | grep -o "T" | wc -l)
    g=$(grep -v "^>" "$file" | tr -d '\n' | grep -o "G" | wc -l)
    c=$(grep -v "^>" "$file" | tr -d '\n' | grep -o "C" | wc -l)

    printf "%-15s %-7s %-7s %-7s %-7s\n" "$file" "$a" "$t" "$g" "$c"
done
```
* `printf "%-15s ..."` — табличный формат: `-15s` означает выравнивание строки влево с шириной колонки в 15 символов.
* `[ ! -s "$file" ]` — проверка: если файл пустой (0 байт), `continue` пропускает его.
* `grep -v "^>"` — исключает строку заголовка FASTA (начинающуюся с `>`).
* `tr -d '\n'` — склеивает многострочную последовательность в одну строку (удаляет переводы строк).
* `grep -o "A" | wc -l` — флаг `-o` выводит каждую найденную букву `A` на новой строке, а `wc -l` (*word count lines*) считает количество строк (вхождений буквы).

### 10. `check_root.sh`
```bash
#!/bin/bash
check_root() {
    if [ "$EUID" -ne 0 ]; then
        echo "Ошибка: запустите скрипт с правами суперпользователя (root)!"
        exit 1
    fi
}

check_root
echo "Скрипт запущен от имени root"
```
* Проверяет эффективный UID пользователя. У обычных пользователей он $\ge 1000$, у `root` всегда `0`.

### 16. `task_3-14_students.sh`
```bash
#!/bin/bash
# 1. Выведет только имена студентов
awk '{print $1}' students.txt

# 2. Выведет только оценки
awk '{print $2}' students.txt

# 3. Выведет номер строки и имя
awk '{print NR, $1}' students.txt
```
* `$1` — первое поле (имя), `$2` — второе поле (оценка), `NR` — номер текущей строки.

### 17. `task_3-14_score.sh`
```bash
#!/bin/bash
# 1. Выведет студентов с оценкой выше 80
awk '$2 > 80' students.txt

# 2. Выведет студентов с оценкой ниже 70
awk '$2 < 70' students.txt

# 3. Только первая строка файла
awk 'NR == 1' students.txt
```
* В `awk` условие перед блоком определяет, к каким строкам применить действие. Если действия `{print}` нет, `awk` по умолчанию выводит всю совпавшую строку целиком (`$0`).

### 18. `task_3-14_stat.sh`
```bash
#!/bin/bash
# 1. Сумма всех оценок
awk '{sum += $2} END {print sum}' students.txt

# 2. Средняя оценка
awk '{sum += $2} END {print sum / NR}' students.txt

# 3. Максимальная оценка
awk 'NR==1{max=$2} $2>max{max=$2} END{print max}' students.txt
```
* Блок `END` выполняется после окончания файла. На этот момент в `sum` накоплена сумма, а `NR` хранит общее число строк (студентов).
* В третьей строке: на первой строке (`NR==1`) принимаем оценку за максимум, далее если встречаем оценку больше (`$2 > max`), обновляем `max`.

### 19. `task_3-14_csv.sh`
```bash
#!/bin/bash
# 1. Выведет названия товаров
awk -F, '{print $2}' data.csv

# 2. Выведет товары дороже 20
awk -F, '$3 > 20' data.csv

# 3. Посчитает общую стоимость
awk -F, '{total += $3} END {print total}' data.csv
```
* Флаг `-F,` задает запятую как разделитель столбцов CSV. `$2` — название товара, `$3` — цена.

### 20. `task_3-14_system_analyze.sh`
```bash
#!/bin/bash
df -h | awk 'NR > 1 {
    val = int($5)
    if (val > 90) {
        print $1, $5, "Предупреждение: заполнение более 90%!"
    } else {
        print $1, $5
    }
}'
```
* `df -h` выводит таблицу смонтированных файловых систем.
* `NR > 1` пропускает заголовок таблицы.
* `int($5)` преобразует строку процента (например, `"85%"`) в число `85`.
* Если процент `> 90`, дописывается строка с предупреждением.

## 6. Шпаргалка к защите (Вопросы преподавателя и ответы)

1. **Вопрос:** *Зачем нужен `chmod +x`?*  
   **Ответ:** Файлы в Linux по умолчанию создаются без бита исполнения в целях безопасности. `chmod +x` добавляет право на выполнение для пользователя, позволяя запустить скрипт как бинарную программу.

2. **Вопрос:** *Почему нельзя ставить пробелы вокруг знака `=` при объявлении переменной?*  
   **Ответ:** Bash парсит строку по пробелам. Если поставить пробел, первый токен воспримется как имя команды, а всё последующее — как аргументы к ней.

3. **Вопрос:** *В чем разница между `exit 0` и `exit 1`?*  
   **Ответ:** Код `0` по стандарту POSIX означает успешное завершение программы без ошибок. Любой ненулевой код (обычно 1) означает ошибку.

4. **Вопрос:** *Почему для ИМТ в `bmi.sh` использовалась команда `bc`?*  
   **Ответ:** Встроенная арифметика Bash `$((...))` поддерживает только целочисленные операции. Рост задается вещественным числом (в метрах, например 1.75), поэтому для работы с дробями нужен внешний калькулятор `bc`.

5. **Вопрос:** *Что делает флаг `-i` в `sed`?*  
   **Ответ:** Флаг `-i` (*in-place*) указывает `sed` изменить сам исходный файл на диске, а не просто вывести результат замены в стандартный поток вывода терминала.

6. **Вопрос:** *Что означают `NR` и `NF` в утилите `awk`?*  
   **Ответ:** `NR` (*Number of Records*) — порядковый номер текущей строки. `NF` (*Number of Fields*) — количество столбцов (полей) в текущей строке.
