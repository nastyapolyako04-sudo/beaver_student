### 🐍 Мой код на Python
В качестве примера я написалa небольшую программу, которая генерирует случайное число и предлагает пользователю угадать его:

```python
import random

def guess_the_number():
    secret_number = random.randint(1, 10)
    print("Привет! Я загадалa число от 1 до 10.")
    
    guess = int(input("Попробуй угадать: "))
    
    if guess == secret_number:
        print("Бинго! Ты угадал! 🎉")
    else:
        print(f"Не угадал. Я загадалa число {secret_number}. Повезет в следующий раз! 😉")

# Запуск игры
guess_the_number()```
